# Mascote JV Busca

Arquivo: `public/assets/jv-mascot.png`, PNG RGBA 480 × 480.

Preparado com a ferramenta de imagem integrada (sem API externa), a partir da imagem enviada pelo usuário. Original de geração preservado na pasta de imagens do Codex; cópia otimizada por redimensionamento para o site.

Prompt: “Edit this supplied mascot image for website use. Isolate ONLY the exact yellow winking fish mascot, remove all Chinese lettering and the yellow background. Faithfully preserve its existing yellow body, white large eyes, black pupil, wink and open smiling mouth, orange fins and illustration shading. Reconstruct the cropped bottom edge minimally to form a complete rounded character. No additions, no text, no badge, no new costume, no props. Transparent PNG, clean smooth edges, mascot centered and filling 85 percent of square canvas. This is an asset cutout, not a redesign.”

Os banners atuais usam composição HTML/CSS e fotos reais dos produtos já coletados. As imagens decorativas dos banners anteriores continuam nos arquivos, mas não são carregadas pela nova página. As setas e os corações são desenhos SVG, sem dependência de fontes de emojis.
