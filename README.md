## 💻 Executar Localmente com Busca ao Vivo

Para rodar com a busca ao vivo no Goofish e o backend Python completo:

```powershell
cd xianyu-search
.\iniciar.ps1
```

O servidor local iniciará em `http://127.0.0.1:8081`.
