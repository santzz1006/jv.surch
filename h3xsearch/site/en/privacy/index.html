Privacy note

H3X Search has no accounts, logins or profiles. To work, it processes what you search for and a code derived from your IP to limit searches. Here is everything that happens, in plain words.

Updated 13 November 2026

When you search

  • Your search term goes to our server, which queries Xianyu listings with it.
  • Results and translations are cached on the server for a while so the same search isn't repeated. The cache doesn't record who searched.
  • Translation: listing titles and, if you turn translation on, your search term are sent to third-party machine translation services (such as Google's and MyMemory).
  • Exchange rate: the server queries public currency services to convert yuan to reais. Nothing about you is sent.

Your IP and the search limit

There is a per-person search limit so nobody exhausts the service. To count, the server turns your IP into a keyed hash and stores only that code and the day's count. Previous days' counts are deleted. The IP itself isn't stored in that record.

Listing images

Photos are loaded by your browser straight from the marketplace's image servers, which therefore receive the request (including your IP), as with any site showing images hosted elsewhere. The site asks your browser not to send the referring page.

Cloudflare

The site runs on Cloudflare. Against bots we use Cloudflare Turnstile (an automatic check in your browser when the search page loads) and Bot Fight Mode, which analyse technical signals from the browser and connection. Cloudflare also keeps technical request logs, which can include the requested address (and so the search term), for a limited time. See Cloudflare's privacy policy.

In your browser

The site stores two preferences in your browser's local storage: your language and whether search translation is on. The site's code has no tracking cookies, ads or analytics. Cloudflare may set technical security cookies related to bot protection.

When you click Buy on Hubbuy

You leave H3X Search for Hubbuy, which has its own privacy rules. The link carries H3xCN's invite code (see Disclosure).
